# Паттерн/абстракция

Я использую реализацию паттерна "самодукоментррубщицся код", но через добавление логирования. 

Это позволяет:  
* Избавиться от минусов изначального паттерна, когда его реализация фактически нарушала бы SR.
* Нивелировать минусы устаревших JavaDoc, которые перестают поддерживать систематически актуализировать.
В то время как логи - исполняемый код, за которым внимательнее следят на ревью и так же на правильность которых смотрят при эксплуатации программы.
