# Многопоточность
1. **synchronized**  
Можно добавить синхронизацию на часть кода требовавшую изменения глобального значения.  
а) Само значение важно пометить volatile, что бы не закэшировалось на одном из процессоров. 
б) синхронизации достаточно только на итерирование глобальной переменной. Цикл с i++ создается каждый в своем потоке.

2. **AtomicInteger**  
Выполняется простая операция, поэтому можно использовать конкретный тип данных для него, решающий проблемы многопоточного изменения.
