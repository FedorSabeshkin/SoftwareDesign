# Инвариант цикла для findMax в массиве

## findMax
``` 
{arr.length > 0} findMax(arr) {result = max(arr)}
I: 0 <= i < arr.length и res >= arr[i]
```

Доказательство инварианта.    
1. Инициализация:    
   До начала первой итерации цикла: i = 0 и res = 0  
   Проверка инварианта: 0 <= n и res >= 0  
   Инвариант истинен в начале.  

2. Сохранение инварианта:  
   Предположим, что инвариант истинен до некоторой итерации цикла, где 1 <= i <= n и res >=i  
   Во время выполнения цикла: k<i И (res = arr[k] ИЛИ res = arr[i]) И i = i + 1  
   После итерации: i увеличивается на 1, следовательно, i = i+1  
   res = arr[i] ИЛИ arr[k] И arr[k] >= arr[i]  
   Таким образом, инвариант по-прежнему истинен: 0 <= i <= n И res >= arr[i]  

Завершение:  
Цикл завершается, когда i становится равным n.  
На этом этапе res  >= arr[i], так как инвариант после последней итерации: i = n и res >= arr[i]  
Следовательно, постусловие выполняется: res >= arr[i]
