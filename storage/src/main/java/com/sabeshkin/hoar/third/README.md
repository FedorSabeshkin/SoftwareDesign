# Тройки Хоара и инвариант для QuickSort

## Тройка Хоара для сортировки
  
{P: arr{n1,...,n}, sort(arr), Q: res={n1, n2,...,nk+1} И n1<=n2<=...<=nk+1}  

    
Предусловие P: массив эллементов.  
Постусловие Q: result массив в котором элемент n[k]<=n[k+1].   

   Лемма:  сортировка {0, n, ..., 0} вернет массив с лидирующими нулями и n в конце массива при n>=0;
   Л1. Доказательство  
   1. Если arr{0, n1}, то sort(arr) возвращает arr{0, n1}, тогда result = {0, n1}.  
   2. Предположим что верно arr{0,..., 0, nk}, sort(arr), Q: res={0, 0,...,nk} И nk>=0
   3. Докажем верность для arr{0,..., 0, nk+1}.  
      Выделим подмассив sub_arr{0,...,0, 0} и массив из одного элемента arr_once{0,..., 0, nk+1}.
      Представим их как вектора в пространстве nk+1  в котором определены операции сложения векторов и умножения вектора на скаляр.  
      Из п.2 предпологаем , что sort(0,..., 0, nk) верно. Примем nk = nk+1., значит сортировка с ним верна. 

Доказательство:  
1. Если arr{n1}, то sort(arr) возвращает arr{n1}, тогда result = {n1}.  
2. Предположим что верно arr{n1,...,nk}, sort(arr), Q: res={n1, n2,...,nk} И n1<=n2<=...<=nk  

3. Докажем верность для  arr{n1,...,nk, nk+1}.  
Выделим подмассив sub_arr{n1,...,nk, 0} и массив из одного элемента arr_once{0,..., 0, nk+1}.  
Представим их как вектора в пространстве nk+1  в котором определены операции сложения векторов и умножения вектора на скаляр.  
Из п.2 предпологаем , что sort(sub_arr) верно. 
sort(arr_once) верно из доказательства сортировки массива с 0.  
Выполним сложение векторов. sub_arr + arr_once = {n1, ..., nk, 0} + {0, ..., 0, nk+1} = {n1, ..., nk, nk+1} И n1<=n2<=...<=nk<=nk+1
