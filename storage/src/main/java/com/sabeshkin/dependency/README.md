# Неявные зависимости
1. Программа сломается.
   Поэтому в gRPC старые поля просто помечаются deprecated, но никогда не удаляются.


2. Перепутаны понятия перегрузки и переопределения метода.
   @Override на первом методе не нужен.


3. Контракт json не строгий. Name может больше не быть и вернет null
