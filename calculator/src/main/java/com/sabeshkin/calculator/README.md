# Функциональный стиль

1. Изначально сделал отдельное DTO, которое позволяет хранить результат успешного выполнения или ошибку, что стандартизирует обработку ответа от метода.
2. Для оценок создал ENUM с заданными значениями.
3. List изменил на ImmutableList, что бы отразить в сигнатуре, что список Не изменяемый.   
Этот вариант мне нравится больше, чем падать в runtime, когда внутри обычного List вдруг может оказаться неизменяемый список.
