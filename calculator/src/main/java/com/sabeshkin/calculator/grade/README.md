# Подстилание соломки для потенциальных изменений
Использовал интерфейс Grade для калькулятора и его реализации для 100 и 5-ти бальных систем.   
Код калькулятора не меняется, а его результаты могут отличаться, например в пяти балльной системе минимальное среднее 2, а в 100 бальной 0.  

Но такое изменение внешнего результата и препологается, как если бы мы меняли систему уведомлений, падавая ей в 1 случае реализацию для отправки email, а в другом отправки sms.
